# استوديو نور — Studio Noor

صفحة هبوط لاستوديو تصميم داخلي: أعمال تجريبية مع بحث وتصفية، وخدمات تصميم، وقصص مشاريع، ومصممون، وآراء تجريبية، وخدمات بعناصر نائبة `{{...}}`، وأسئلة شائعة، ونموذج طلب استشارة مع تحقق وحفظ في المتصفح.

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
npm run preview
```

ثنائية اللغة (العربية RTL والإنجليزية LTR) مع زر تبديل وحفظ اللغة في `localStorage`. لا توجد متغيرات بيئة.
